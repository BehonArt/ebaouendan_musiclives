Elite Beat Ouendan: Music LIVES  @VERSION@
==========================================

Elite Beat Agents, Osu! Tatakae! Ouendan and Moero! Nekketsu Rhythm Damashii
Osu! Tatakae! Ouendan 2, recompiled from the Nintendo DS to run natively on
Windows, with options the DS never had.

Getting started
---------------
1. Unzip this folder anywhere.
2. Run eba-recomp.exe (the launcher).
3. For each game, choose your own dump of its cartridge (.nds), or drop it on
   the launcher's window. It needs these dumps, unmodified:
     Elite Beat Agents                 the USA cartridge (AOSE)
     Osu! Tatakae! Ouendan             the Japanese cartridge (AOSJ)
     Osu! Tatakae! Ouendan 2           the Japanese cartridge (AO2J)
   Nothing of the games is included in this download.
4. Press Play.

Windows may warn that the program is from an unknown publisher (it is not
signed): choose "More info", then "Run anyway".

In a game
---------
F1 shows or hides the options bar: Display (resolution up to 4K, layout,
frame rate, Vsync, fullscreen), Look (picture filter),
Input (Tap mode for gamepads and keys, rumble), Timing (offset and
calibration), Assist (approach speed, hit circle, No-Fail), Effects (fire).
F11 or Alt+Enter: fullscreen. F12: a screenshot. Esc: quit.

The mouse is the stylus. In Tap mode a gamepad's face buttons or d-pad (or
Space) tap the note on the beat; hold through sliders; for spinners, mash,
pull the triggers, or turn the left stick round.

Saves and settings are kept in %APPDATA%\eba-recomp. To keep them beside the
program instead, put an empty file named portable.txt next to
eba-recomp.exe.

Needs: Windows 10 or 11 (64-bit), a graphics card with OpenGL 4.5.
