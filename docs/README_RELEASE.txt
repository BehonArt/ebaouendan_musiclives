Elite Beat Ouendan: Music LIVES  @VERSION@
==========================================

Elite Beat Agents, Osu! Tatakae! Ouendan and Moero! Nekketsu Rhythm Damashii
Osu! Tatakae! Ouendan 2, recompiled from the Nintendo DS to run natively on
Windows, with options the DS never had.

Discord (customs, help, bug reports): https://discord.gg/XGPhewDEtn

Getting started
---------------
1. Unzip this folder anywhere. (With Quiver, it's installed for you.)
2. Run eba-recomp.exe (the launcher).
3. For each game, choose your own dump of its cartridge (.nds), or drop it on
   the launcher's window. It needs these dumps, unmodified:
     Elite Beat Agents                 the USA cartridge (AOSE)
     Osu! Tatakae! Ouendan             the Japanese cartridge (AOSJ)
     Osu! Tatakae! Ouendan 2           the Japanese cartridge (AO2J)
   Nothing of the games is included in this download.
4. Press Play.

Windows may warn that the program is from an unknown publisher (it is not
signed): choose "More info", then "Run anyway". The first start can be slow
while antivirus checks it.

In a game
---------
The mouse is the stylus: this is the game as made.

To play with a controller or keyboard, press F1 and turn on Input > Tap mode.
A gamepad's face buttons or d-pad (or Space) then tap the note on the beat; hold
through sliders; for spinners, mash, pull the triggers, or turn the left stick
round. Rumble and DualSense trigger resistance come with it.

F1 shows or hides the options bar: Display (resolution up to 4K, layout,
frame rate, Vsync, fullscreen), Look (picture filter), Input (Tap mode, rumble,
keys), Timing (offset and calibration), Assist (approach speed, hit circle,
No-Fail), Effects (fire).
F11 or Alt+Enter: fullscreen. F12: a screenshot, in the game's save folder.
Esc: quit.

Customs
-------
Game > Customs (or the CUSTOMS button on the main menu) plays custom songs over
the games' stages. They are apart from your campaign: any stage can be played
whatever your progress, and scores are kept separately.

No songs are included. To add one someone has shared as a patch (.bps), apply it
to your own dump of the game with Flips or Rom Patcher JS, then use Import custom
ROM on the Customs screen. The first Play prepares Customs for a few seconds.

To make your own, open Customs Studio (the button at the bottom of the launcher).
Its guide is CUSTOMS STUDIO GUIDE.md, in this folder.

RetroAchievements
-----------------
Game > RetroAchievements signs in with your account (casual mode). Achievements
count when a game is played as made: by touch (the mouse), with no assists.
Customs, or using Tap mode's buttons in a song, pauses them for that song.

Your files
----------
Saves, settings, screenshots and customs are kept in %APPDATA%\eba-recomp, so
updates never touch them. To keep them beside the program instead, put an empty
file named portable.txt next to eba-recomp.exe.

If something goes wrong
-----------------------
If a game says it needs OpenGL 4.5 or will not open, update your graphics driver.
Each game's log is in its save folder (the launcher's Save folder button). Post it
on the Discord with your graphics card and Windows version.

Needs: Windows 10 or 11 (64-bit), a graphics card with OpenGL 4.5.
